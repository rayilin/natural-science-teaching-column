## 二、更新內容的方式

1. 修改 `教學網頁/` 裡的檔案。
2. commit + push 到 `main`。
3. GitHub Actions（`.github/workflows/pages.yml`）會自動重新發佈，約 1 分鐘後生效。

發佈時會**排除** `server.js`、`questions.json`、`start-battle.bat`、`package.json`，
所以題庫答案不會出現在公開網站上（已實測 `questions.json` 回 404）。

## 三、對戰遊戲的三種運作方式

對戰需要一台會跑 Node 的伺服器，GitHub Pages 只能放靜態檔，所以有三條路：

### 1. 雲端版（學生不用同一個 Wi-Fi）

需要把 `server.js` 部署到免費 Node 平台（本專案已備好 `render.yaml`）。

Render 部署步驟（約 3 分鐘）：

1. 開 https://render.com → 右上 `Get Started`／`Sign in` → 用 GitHub 帳號登入並授權。
2. 右上 `New +` → `Blueprint`。
3. 選 `rayilin/natural-science-teaching-column` → `Apply`。
   （Blueprint 會自動讀取 `render.yaml`，服務名稱是 `plant-battle`，方案 Free。）
4. 等狀態變成 `Live`，複製網址，格式像 `https://plant-battle.onrender.com`。
5. 把這個網址填進 `教學網頁/battle-api.js`：

   ```js
   window.BATTLE_API = 'https://plant-battle.onrender.com';
   ```

   commit + push 後，GitHub Pages 上的對戰區就會自動連到雲端。

也可以用網址參數臨時指定，不必改檔：
`https://rayilin.github.io/natural-science-teaching-column/battle.html?api=https://plant-battle.onrender.com`

免費方案的限制：閒置 15 分鐘會休眠，第一個人連線要等 30～60 秒（畫面會顯示「正在連線對戰伺服器」）；上課前先開一次讓它醒著就好。

### 2. 教室區網版（不依賴網路，最穩）

1. 老師電腦雙擊 `教學網頁/start-battle.bat`（或 `node server.js`）。
2. 學生用同一個 Wi-Fi 開 `http://老師電腦IP:8765/battle.html`。
3. 第一次啟動時 Windows 防火牆要允許 Node.js 存取私人網路。

這個模式 `battle-api.js` 保持空字串即可（預設就是同網站的 `/api`）。

### 3. 沒接後端時

對戰區會顯示「先啟動對戰伺服器」與操作步驟，其他內容（簡報、測驗、影片）完全正常。
